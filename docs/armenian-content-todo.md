# Հայերեն բովանդակություն՝ հաստատման սպասող կետեր

**Baseline.** Ներկա վիճակը (Sanity, `data/gos` import source, `messages/hy.json`,
import logic) համարվում է հաստատված։ Ստորև նշված կետերից ոչ մեկը չի փոխվել․
յուրաքանչյուրը սպասում է պատվիրատուի կամ բժշկական մասնագետի որոշմանը։

Բոլոր կետերը ստուգված են ռուսերեն բնագրի դեմ (`data/gos/<slug>.json`, scrape
gyumriorthoschool.org-ից)։ Sanity-ի ճանապարհները տրված են document id + field
ձևով (`[hy-…]`-ը block-ի կամ row-ի `_key`-ն է)։

Բժշկական տերմինները՝ առանձին փաստաթղթում․ `docs/armenian-medical-terminology-review.md`։
